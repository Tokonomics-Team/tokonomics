## Implemented controls

- All production upstream model sends now pass through one canonical provider gateway.
- The final boundary rechecks cancellation, trust, explicit workspace-context consent, source-policy
  completion, paths, secrets, indirect prompt injection, payload size, cycles, depth, and typed values.
- Text, tool calls/results, JSON/XML/script text, and supported images have explicit handling.
  Unknown object prototypes, non-finite values, unsupported MIME types, and unknown parts fail closed.
- Workspace reads enforce real-path containment, multiple roots, ignore rules, sensitive filenames,
  regular files, size ceilings, binary detection, and a second check on the opened file.
- Restricted Mode performs no workspace initialization or parser preparation in the tested path while
  allowing explicit user-authored prompt text.
- Dashboard nonces use cryptographic randomness and the CSP allows no network connection, remote font,
  unsafe inline script, or evaluation source.
- Project memory has no built-in encryption material. Persistence is unavailable unless an injected
  secret-store key provider supplies at least 256 bits, and ciphertext uses a versioned envelope.
- Operational logs, receipts, UI errors, and crash exports use content-free reason codes or sanitized
  stack frames rather than raw exception messages.
