# Tokonomics v7.0.1 — Phase 7 validation

## Result

PASS. LSP, diagnostics, tests, Git, delta, terminal, and provenance are now production-conditional evidence sources. Their bounded output is admitted through the canonical evidence selector, and contribution is recorded only when the final selected set contains that source's content hash.

## Implemented controls

- LSP and six development-signal components promoted from shadow-only to independently flag-gated production capabilities.
- LSP results and coordinated signals enter the same snapshot-bound evidence request as lexical/symbol evidence.
- Workspace generation and document versions are validated as separate freshness domains.
- One-based index coordinates normalize to zero-based LSP positions at the adapter boundary.
- Whole signal snapshots fail closed on generation mismatch.
- Buffer-backed diagnostics compare against buffer versions; disk snapshots do not invent editor versions.
- Terminal evidence requires an authorized source, consent, sanitization, and a five-minute freshness window.
- Contribution receipts compare admitted content hashes; zero/not-admitted cases receive stable fallback codes.
- Provenance contribution requires every admitted candidate to carry provenance.

## Automated evidence

| Gate | Command | Result |
|---|---|---|
| Type safety | `npm.cmd run compile` | PASS |
| Full automated suite | `npm.cmd test` | PASS |

Coverage includes position normalization, stale document and generation rejection, timeout/cancellation, root containment, huge-result bounds, missing APIs, signal precedence, terminal consent/secret/injection sanitization, expired terminal data, production call-graph reachability, and receipt truth.

## Security and privacy review

Terminal and external development signals remain hostile input and pass through source authorization, redaction, provenance, selection, preservation, and final egress validation. Signal receipts and reasons contain identifiers/codes only, never raw content.

## Rollback

Each source has an independent feature flag. Disabling a source returns retrieval to the approved workspace snapshot lexical/symbol baseline without blocking prompt processing.
