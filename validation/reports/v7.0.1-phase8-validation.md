# Tokonomics v7.0.1 — Phase 8 validation

## Result

PASS. Local hybrid retrieval, bounded interaction reranking, MMR, and provenance-aware deduplication now affect the production-selected evidence when Maximum Savings is selected. Balanced remains on the deterministic lexical/symbol baseline.

## Implemented controls

- Incremental snapshot indexing populates bounded vectors before dense retrieval is reported active.
- Dense candidates resolve renderable text only from the pinned snapshot and enter canonical selection as typed evidence.
- Reranking is capped at 32 selected candidates; deduplication is capped at 64.
- MMR reorders without dropping candidates, preserving mandatory evidence and dependency closure.
- Deduplication retains protected evidence, semantic distinctions, dependencies, and merged provenance.
- Each stage records contribution only when the admitted order/set changes.
- All four enhancements have independent flags and deterministic fallback.
- Built-in representations are explicitly labeled `hashed_lexical_projection` and `lexical_interaction`; no learned-model claim is made.

The combined suites cover vector normalization, model/dimension mismatch, empty/corrupt vectors, quota/LRU invalidation, snapshot reconciliation, hybrid fallback, top-k bounds, cancellation/deadline behavior, MMR stability/diversity, exact/lexical/vector deduplication, adversarial distinctions, protected evidence, provenance merging, production index population, applied stage order, and truthful receipts.

## Security and privacy review

Representations are local derived data, bounded in memory, invalidated by source content/version, and never sent as model-visible vectors. Rendered candidates still pass provenance, preservation, source policy, and final egress checks.

## Rollback

Disable dense, interaction reranking, MMR, or dedup independently. Balanced lexical/symbol retrieval remains available and does not depend on these stages.
