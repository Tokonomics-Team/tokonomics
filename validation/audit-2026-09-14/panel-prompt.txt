2. SYSTEM INVARIANTS & CORE THESIS TO ENFORCE
The extension under audit operates under strict non-negotiable invariants:

100% Local-Only Execution (Zero-Leak Boundary): Zero outbound HTTP/WebSocket network calls to unauthorized third-party services. All parsing, slicing, indexing, and compaction must execute on-device.

Correctness > Token Reduction: When a task is high risk, evidence safety gates must strictly override token reduction. Mathematical invariant: RequiredEvidence ⊆ ProvidedEvidence.

Strict Build & Runtime Isolation: The non-production validation plane (validation/, benchmarks, evaluators) must be 100% isolated and never packaged or imported into the production runtime (src/) or the production .vsix bundle.

Append-Only Cache Prefix Invariant: Static system prompts, schemas, and maps must maintain deterministic byte-for-byte prefix ordering to protect cloud prompt-cache hit rates (Anthropic 1,024-token boundaries; OpenAI/Gemini static prefixes).
